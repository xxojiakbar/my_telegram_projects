# Telegram Avtomatik Javob Dasturi

Ushbu loyiha Python dasturlash tili va Telethon kutubxonasi yordamida yaratilgan.

Dastur shaxsiy Telegram akkauntiga kelgan shaxsiy xabarlarni kuzatadi va salomlashuv so‘zlarini aniqlab, avtomatik javob qaytaradi.

### Dasturning vazifasi

- Telegram akkauntiga ulanish.
- Kelgan shaxsiy xabarlarni tekshirish.
- Salomlashuv so‘zlarini aniqlash.
- Aniqlangan salomlashuvlarga avtomatik javob berish.

### Foydalanilgan texnologiyalar

- Python
- Telethon
- python-dotenv
- pathlib
- os

### Maqsad

Python kutubxonalari bilan ishlash, Telegram API'ga ulanish, xabarlarni qayta ishlash va avtomatlashtirish bo‘yicha amaliy bilimlarni oshirish.
